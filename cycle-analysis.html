  • 大盘强月：2月 / 11月 / 9月 / 6月；弱月：10月（"五穷十弱"十年成立）。
  • 行业月份特征：7月=周期超级月（有色+9.8%/钢铁+9.5%/化工+7.6%/电力设备+8.4%）；2月=春节躁动（计算机+8.2%/钢铁+6.9%/通信+7.2%）；11月=年末政策月（传媒+4.3%/地产+5.1%/建筑+4.6%/非银+4.2%）。
  • 弹性（σ）最大：钢铁4.35 / 化工4.19 / 地产3.85 / 有色3.36（博拐点首选）；银行最稳1.48（防御桶）。
关联你的账户：当前8月初临近9月煤炭旺季（煤炭强月9月+4.7%/1月+4.2%），但神华受"降煤电量"政策逆风+技术破位，不按季节盲加；7月是周期大月，你7月砍方正/东方电气正好错过——佐证"风格切换"反思；10月双弱需警惕。
方法论：行业=代表性龙头等权代理（非官方申万指数），因 eastmoney 源被沙箱挡、baostock 无申万指数；结论方向稳健，绝对值略偏大盘龙头。
